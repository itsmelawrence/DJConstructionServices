# D&J Construction Services landing page

Open `index.html` in a browser, or serve this directory with a local static server. The page has no build step or third-party runtime dependencies.

## Design direction

- **Palette:** pine `#183d38`, deep pine `#102e2d`, paper `#f8faf8`, mist `#e9efeb`, sage `#b7cabc`.
- **Type:** Avenir Next where available, then Avenir or Segoe UI. The supplied D&J logo provides a contrasting display treatment.
- **Layout:** `[logo header] → [full-width exterior photo + overlaid message] → [editorial question] → [kitchen image + copy] → [service ledger] → [family story] → [contact and footer together]`.
- **Alignment:** Left-aligned copy; the photography and large type supply the visual scale.
- **Distinctive choice:** The exterior is the hero canvas rather than one side of a split hero. The services form a ledger rather than cards, and contact is integrated into the footer. This replaces the earlier structure that echoed the Phoenix Pro Roofing page.
- **Motion:** The hero settles into place; text, imagery, and service rows have different entrance treatments. Hover responses indicate actions. Reduced-motion preferences turn these effects off.

The logo, exterior image, and kitchen image were supplied for this project. Business name, services, family ownership, founder, contact details, and ROC number were checked against [D&J's website](https://www.dandjconstructionservices.com/), its [About page](https://www.dandjconstructionservices.com/about), and its [Contact page](https://www.dandjconstructionservices.com/contact). Contact buttons lead to D&J's published contact page; phone and email links use the published details.
